# Big-Brother-29# Big Brother 29: BB House Party — Independent Setup Build

This is a fresh, independent BB29 simulator project. It does not reuse code or assets from any of your previous simulator projects. The interface is an original BB House Party design using a compact season-control layout inspired by the general workflow of browser-based Big Brother simulators.

## Run locally
1. Unzip the folder.
2. Open `index.html` in a modern browser.
3. Use the left navigation to edit the cast, starting relationships, schedule, and twist reference.
4. Click **Save Season** to save in the browser's local storage. Use Export JSON to make a portable backup.

## Included in this first build
- BB House Party branding and responsive layout.
- The supplied 16-houseguest starting cast.
- Editable names, gender, portrait image URLs, bios, and five attributes (General, Physical, Mental, Social, Strategic).
- Editable pairwise starting relationships (Friendship, Trust, Loyalty, Rivalry, Respect, Attraction).
- The provided 14-week HOH/POV/special competition lineup.
- Party Host, Snag & Grab, Roommates, America's Invitation, and Jury Battle Back rule reference.
- Browser save, JSON export, and JSON import.

## Important scope note
This is **Setup Build 1.0**, not yet the playable simulation engine. It does not currently run HOH/POV outcomes, nominations, veto ceremonies, votes, evictions, jury voting, or placement calculations. Those systems should be implemented as the next development stage and tested against the twist rules before the simulator is described as complete.

## Deployment
The project is static HTML/CSS/JavaScript and can be hosted on GitHub Pages. Upload the contents of this folder to a new repository and enable Pages for the main branch/root.
